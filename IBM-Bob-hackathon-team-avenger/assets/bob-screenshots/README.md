# Bob Screenshots

Screenshots of IBM Bob in action with the Cortex extension.

## Required screenshots for submission

| File | Description |
|---|---|
| `01-bob-cortex-mode.png` | Bob with 📓 Cortex mode active |
| `02-diary-save-command.png` | `/diary-save` slash command in use |
| `03-proactive-recall.png` | Bob auto-surfacing entries on file open |
| `04-agentic-auto-capture.png` | Bob proposing a draft entry after task completion |
| `05-mcp-tools-connected.png` | MCP Inspector showing all 5 tools connected |
| `06-diary-recall-results.png` | `diary_recall` results with file:line citations |

## How to capture

1. Start the stack: `make start`
2. Open IBM Bob → switch to `📓 Cortex` mode
3. Use the MCP Inspector (`make verify-mcp`) to confirm tools are connected
4. Perform each action and screenshot with your OS screenshot tool
5. Save files here with the names above

## Notes

- Use 1920×1080 or 2560×1440 resolution
- Crop to show the relevant Bob panel
- Redact any personal tokens or API keys before saving
